# 高機能画像ファイル変換ツール

高効率な画像処理エンジン（Sharp, heic-convert, @imgly/background-removal-node）を備えた画像変換・編集Webアプリケーションです。

## 主な機能

1. **トリミング**: 対話型GUI（`react-image-crop`）による矩形選択と、元サイズ・クロップ枠サイズのリアルタイム表示
2. **傾き補正・回転**: -180° 〜 +180° のスライダー調整およびリアルタイムプレビュー（余白はアルファ透過PNG処理）
3. **サイズ変更**: 幅・高さの個別指定、アスペクト比固定トグル、複数画像の一括処理
4. **切り抜き・背景透過**: OSS AIモデルを用いた被写体の自動切り抜きと透過PNG出力
5. **ファイル形式変換**: HEIC, JPG, PNG 相互の完全変換、複数画像一括変換（自動ZIPアーカイブ化）
